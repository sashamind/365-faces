# 365 лиц

Фотопроект: один портрет на каждый день года.
Статический сайт — HTML/CSS/JS без сборки, хостится на GitHub Pages.

## Как добавлять фотографии

Клади исходники как есть (например, выгрузку из Instagram) в `photos/faces/`:

```
photos/faces/
  025_Dasha/       ← день 25, имя «Dasha» (имя — после _ или -)
    любое-имя.jpg  ← порядок в серии — по имени файла
    ещё.jpg
  026_/            ← можно без имени
    фото.jpg
```

И один раз запусти подготовку (первый раз — `npm install`):

```bash
npm run prepare-photos
```

Скрипт [prepare-photos.js](prepare-photos.js) для каждого дня:
- срезает рамки-паспарту (белые, кремовые, цветные);
- кадрирует под 2:3 по центру и уменьшает до 1200×1800 максимум;
- выкидывает точные дубликаты;
- пишет готовую папку `photos/025-Dasha/1.jpg, 2.jpg…, thumb.jpg`
  и пересобирает `people.json`.

Потом коммит и пуш. Исходники `photos/faces/` в гит не попадают — только
готовые фото. Папка дня пересоздаётся целиком при каждом запуске, так что
исходник в `faces/` — главный: поменял там — перезапусти скрипт.

На сайте реальные фото идут первыми в сетке, остальные дни —
картинки-заглушки (picsum). Главное фото при каждой загрузке — случайное
из реальных.

**Правила:**
- Номер дня: 1–365, ведущие нули не важны (`25`, `025` — одно и то же)
- Форматы: jpg, jpeg, png, webp, avif
- Рамка срезается, если она однотонная, светлая или яркая и есть со всех
  четырёх сторон. Тёмный фон рамкой не считается — его не трогаем.
- Если кадрирование по центру где-то режет лицо — подготовь этот файл
  вручную в 2:3 и положи сразу в `photos/025-Dasha/` вместо сгенерированного.

## Ручной вариант

Готовые фото 2:3 можно класть сразу в `photos/025-Имя/1.jpg, 2.jpg…`
и пушить — GitHub Action пересоберёт `people.json` и создаст недостающие
`thumb.jpg`. GitHub не любит файлы больше нескольких МБ, а Pages ограничен
~1 ГБ на сайт — сжимай заранее.
