# 365 лиц

Фотопроект: один портрет на каждый день года.
Статический сайт — HTML/CSS/JS без сборки, хостится на GitHub Pages.
Фотографии лежат в Supabase Storage, в гит не попадают.

## Как добавлять фотографии

Раскладываешь папки в `photos/` локально и запускаешь один скрипт:

```
photos/
  025-Елена/       ← день 25, имя «Елена» (имя — после дефиса)
    1.jpg          ← фото серии, по порядку: 1.jpg, 2.jpg, 3.jpg...
    2.jpg
    thumb.jpg      ← необязательно: маленькое превью для сетки
  107/             ← можно без имени
    1.jpg
```

```bash
node upload-photos.js
```

Скрипт зальёт файлы в Supabase и обновит записи. Сайт подхватит их сразу,
пушить в гит ничего не нужно — папка `photos/` в `.gitignore`.

Дни без фотографий показываются с картинками-заглушками (picsum),
так что сайт выглядит целым на любом этапе наполнения.

**Правила:**
- Номер дня: 1–365, ведущие нули не важны (`25`, `025` — одно и то же)
- Форматы: jpg, jpeg, png, webp, avif
- Повторный запуск перезаливает файлы поверх — можно спокойно обновлять

## Размеры фотографий

| Файл | Размер | Формат |
|---|---|---|
| `1.jpg`, `2.jpg`… | 1200×1800 | JPEG, качество ~80 |
| `thumb.jpg` | 400×600 | JPEG, качество ~75 |

Пропорция 2:3, вертикальные. Другие пропорции обрежутся по центру —
лица лучше держать в средней трети кадра.

## Настройка (один раз)

Для заливки нужен `service_role` ключ. Создай файл `.env` в корне:

```
SUPABASE_SERVICE_KEY=eyJ...
```

Ключ: Supabase → Settings → API → `service_role`.
Файл в `.gitignore`, в репозиторий не попадёт — ключ даёт полный доступ к базе.

## Ссылки на конкретный день

`https://…/#25` — откроется сразу день 25. Хэш обновляется при выборе
человека, так что любой момент можно шарить прямой ссылкой.
