# 365 лиц

Фотопроект: один портрет на каждый день года.
Статический сайт — HTML/CSS/JS без сборки, хостится на GitHub Pages.

## Как добавлять фотографии

Никакой JSON руками писать не нужно. Просто клади папки в `photos/` и пуш:

```
photos/
  025-Елена/       ← день 25, имя «Елена» (имя — после дефиса)
    1.jpg          ← фото серии, по порядку: 1.jpg, 2.jpg, 3.jpg...
    2.jpg
    thumb.jpg      ← превью для сетки; если нет — Action создаст сам
  107/             ← можно без имени
    1.jpg
```

После пуша GitHub Action сам пересоберёт `people.json` и создаст недостающие
превью `thumb.jpg` (400×600, обрезка по центру первого фото серии).
Заменил `1.jpg` — удали старый `thumb.jpg`, чтобы превью пересоздалось.
Дни, для которых нет папки, показываются с картинками-заглушками (picsum).

Проверить локально: `node generate-data.js` и открыть `index.html`
(для превью локально нужен `npm i sharp`, иначе скрипт их просто пропустит).

**Правила:**
- Номер дня: 1–365, ведущие нули не важны (`25`, `025` — одно и то же)
- Форматы: jpg, jpeg, png, webp, avif
- Пропорции фото: 2:3 (вертикальные), другие будут обрезаны по центру

## Размеры фотографий

| Файл | Размер | Формат |
|---|---|---|
| `1.jpg`, `2.jpg`… | 1200×1800 | JPEG, качество ~80 |
| `thumb.jpg` | 400×600 | JPEG, качество ~75 |

Лица лучше держать в средней трети кадра. Сжимай фото перед пушем —
GitHub не любит файлы больше нескольких МБ, а Pages ограничен ~1 ГБ на сайт.

## Ссылки на конкретный день

`https://…/#25` — откроется сразу день 25. Хэш обновляется при выборе
человека, так что любой момент можно шарить прямой ссылкой.
